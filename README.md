# PW · 个人网站

一个用于展示和记录我的爱好、思维与日常生活的个人空间。

内容围绕铁路、旅行、语言、音乐和个人随笔展开，同时包含仅创建者本人可访问的私密档案空间。

## 项目定位

- 用于个人表达、兴趣分享和生活记录。
- 暂不加入职业作品集、办公工具或工作项目展示。
- 支持长文章、短记、照片和专题内容。
- 重视阅读体验，兼顾电脑和安卓手机。
- 网站名称和视觉风格暂未确定，PW 为当前项目代号。

## 公开内容

### 交通与地图
铁路、航空、城市交通、线路历史与交通地理观察。

### NIMBY Rails
自建铁路网络、线路构想、运行方案和规划记录。

### 旅行与散步
旅行记录、路线计划、城市观察，以及日常散步中的照片与感受。
明确区分实际旅行、旅行计划和资料研究。

### 语言与文化
英语、日语和法语学习中的发现，包括影视台词、地名、表达方式与跨文化观察。

### 音乐
听后感、歌单和音乐相关的生活记录。

其中设置夜鹿（ヨルシカ）专题，包含：
- 歌曲听后感
- 由歌曲启发的小说和其他文字创作
- 圣地巡礼资料、计划与记录
- 音乐与个人经历的关联

### 日常与随笔
生活片段、自我观察、情绪、关系和其他思考。

### 关于我
个人介绍、兴趣和网站建立的初衷。
公开个人信息的范围由创建者决定。

## 私密空间

暂称“记忆阁楼”，仅创建者本人可访问。

计划支持：
- 私密日记与往事记录
- 私密照片与相册
- 日期、事件、地点和人物标签
- 人物索引与时间线
- 保留原始记录，并追加带日期的回看笔记
- 内容备份与导出

私密内容要求：
- 使用真实身份验证和服务端权限检查。
- 日记、照片原图及附件均需要访问保护。
- 不通过隐藏网址或前端按钮实现权限控制。
- 不将真实私密内容或访问密钥提交到 Git 仓库。
- 私密内容不得进入公开搜索、首页更新或公开构建资源。
- 开发和测试阶段使用明确标注的虚构示例内容。

## 内容管理

创建者应能通过管理界面：
- 新建、编辑和发布文章
- 保存草稿和发布短记
- 上传照片并添加说明
- 管理栏目和标签
- 明确选择内容为公开或私密

私密内容默认保持私密，公开发布需要明确操作。

## 手机体验

- 优先做好手机阅读、日记编辑和照片上传体验。
- 第一阶段计划支持可安装的 PWA。
- 后续评估通过 Capacitor 构建安卓 App。
- 网页与 App 共用内容、账号和权限系统。
- 离线草稿与同步功能按开发阶段逐步实现。

## 开发计划

1. 整理需求并确定技术方案。
2. 使用示例内容完成页面原型。
3. 实现内容管理与公开发布。
4. 实现并验证私密空间权限。
5. 完成手机体验、备份和部署。
6. 根据实际使用情况评估安卓 App。

## 开发原则

- 优先选择适合个人长期维护的方案。
- 不编造创建者的经历、文章或个人资料。
- 示例内容必须明确标注。
- 技术选型需考虑私密权限、手机体验、成本与备份。
- 将详细需求保存在 docs/site-brief.md。
- 将持续适用的开发指令保存在 AGENTS.md。
